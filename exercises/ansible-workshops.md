# Ansible Workshops

These beginner-level and advanced workshops introduce you to running Ansible Automation Platform (AAP). Since the content overlaps, please only enroll in one workshop per persona and choose the workshop best suited for your role.

> **NOTE:** This content has been updated to reflect the latest changes from the Ansible Automation Platform 2.0 release. [Learn more about how the 2.0 release impacts workshops](https://docs.google.com/presentation/d/1VK8rF2jB6jqlcjgUzONBEGm8seqL6bfzFeyOwohICH4/edit?usp=sharing) or watch the [video walkthrough](https://www.youtube.com/watch?v=Oe1AbAvn9gg).
