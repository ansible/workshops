# Automation Everywhere

Automation Everywhere is a 3-hour event that should be run for a small group of accounts in which a Red Hat Ansible Automation Platform opportunity has been identified. These accounts need some additional nurturing to help close the opportunity. The non-technical event is targeted at the opportunity decision maker and key influencers on the opportunity.

These are not meant to provide technical overviews of the products — for all technical considerations, please view our [Ansible technical workshops](ansible-workshops.md). Available event themes include: Business value of automation, network automation, infrastructure automation and cloud automation.

## Sample agenda

Choose from four pre-packaged event agendas that best align with the account opportunity. To decide which event topic is right for your account(s), determine what the single biggest barrier to closing the opportunity might be.

### Business Value of Automation

* Opening Keynote + Strategy (20 min)
* Transformative automation: Be an automation champion (30 min)
* Automation for Managers open Discussion (20 min)
* Break (30 min)
* Automation Architects — CoP and how to get started (30 min)
* Automation as a strategy for risk mitigation (20 min)
* Consulting session — Interactive whiteboard sessions (15 min)
* Closing Session — key takeaways + Q&A (15 min)

### Network Automation (edge)

* Opening Keynote + Strategy (20 min)
* Trends in Network and Edge automation (30 min)
* Network at scale and Edge (30 min)
* Break (20 min)
* Network and edge automation for your multi-vendor environment (30 min)
* Closing (15 min)

Additional themes for infrastructure automation and cloud automation are available in the [Event kit](https://docs.google.com/presentation/d/1_tw8dwmnvVYH94ZKOViAPUb3R1Ka-LCR1nGK1ZKGUrg/edit?usp=sharing).

## When to run Automation Everywhere

Solution consideration stage — for accounts where an Ansible Automation Platform opportunity has been identified and needs additional nurturing.
